# 带键盘事件的计算器（实验一）

东莞理工学院 Qt 应用程序开发课程实验一：实现一个支持鼠标和键盘输入、
能完成四则运算与常用单操作数运算的计算器。

## 功能

- 双操作数四则运算：+ − × ÷，支持小数、连续运算
- 单操作数运算：±（正负切换）、%（百分比）、x²（平方）、√x（平方根）、1/x（倒数）
- 编辑功能：退格 ⌫、CE（只清当前输入）、C（全部复位）
- 异常输入处理：连续小数点、连续运算符、前导零、除数为 0、负数开平方、0 求倒数
- 键盘输入：数字、小数点、+ - * /、回车(=)、退格、Esc(C)、Delete(CE)、F9(±)，
  键盘与鼠标复用同一套槽函数（按键映射表 + animateClick）

## 编译

Qt 6 + MinGW（qmake）：

    qmake Calculator.pro
    mingw32-make release

或直接用 Qt Creator 打开 Calculator.pro 构建。

## 目录说明

- mainwindow.ui  UI 设计器布局（QGridLayout 按键区 + QLineEdit 显示区）
- style.qss      界面样式表（经 resources.qrc 打包进可执行文件）
- mainwindow.h/cpp  计算器逻辑与键盘事件处理

## 已修复的问题

1. 除数为 0：显示"错误"并复位运算状态，避免后续输入拼接在提示文字后
2. 连续小数点（5..6）：输入前检测当前数字是否已含小数点
3. 前导零（007）：新数字直接覆盖显示区
4. 按钮抢占焦点导致键盘事件收不到：全部控件 Qt::NoFocus
